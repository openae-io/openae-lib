# Get Started

## Install

The Python library can be easily installed with `pip`:

```shell
$ pip install openae-core
```

:::{note}
The distribution is named `openae-core` because PyPI's typo-squatting policy prohibits the name `openae`, see [pypi/support#5968](https://github.com/pypi/support/issues/5968). The import name is unchanged:

```python
import openae.features
```
:::
